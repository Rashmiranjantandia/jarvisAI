# JARVIS OS — Product Roadmap

## Current Version: v1.0.0

Released June 30, 2025. Core feature set complete and stable.

---

## v1.1 — Stability & Polish
*Target: Q3 2025*

- [ ] Mobile responsive layout (collapsible sidebar, touch-friendly panels)
- [ ] Improved error boundaries per panel
- [ ] Export conversation history as Markdown/PDF
- [ ] Session tagging and search in Memory panel
- [ ] Dark/light theme toggle with system preference detection
- [ ] Accessibility audit (ARIA labels, keyboard focus management)

---

## v1.2 — Extended Voice
*Target: Q4 2025*

- [ ] Custom wake word training (replace double-clap)
- [ ] Voice command history and replay
- [ ] Multi-language support (Web Speech API language switching)
- [ ] Voice-controlled task creation ("Add task: review architecture")
- [ ] SSML support for richer TTS output

---

## v2.0 — Plugin System
*Target: Q1 2026*

- [ ] JARVIS Skill API — pluggable command handlers
- [ ] Weather skill — real-time weather briefings
- [ ] Calendar skill — Google Calendar integration
- [ ] News skill — morning news briefing
- [ ] Timer/reminder skill — voice-set reminders
- [ ] Code execution skill — sandboxed JavaScript runner

---

## v2.1 — Cloud Features
*Target: Q2 2026*

- [ ] Optional user authentication (NextAuth.js)
- [ ] Cloud session sync (encrypted, opt-in)
- [ ] Cross-device state persistence
- [ ] Webhook triggers — automate external services via voice
- [ ] JARVIS API — expose voice commands to external apps

---

## v3.0 — Multimodal
*Target: Q3 2026*

- [ ] Image analysis — drag-and-drop image chat
- [ ] Document processing — PDF summarization
- [ ] Screen capture awareness — "What's on my screen?"
- [ ] Real-time transcription mode — continuous voice logging
- [ ] Vision-based command recognition (camera gesture control)

---
